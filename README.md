### 🚀 Highlighted Data Projects

#### 🎬 [CineDex — Automated Media Data Ingestion & Storage Engine](https://github.com/xpmahdi/CineDex)
* Built an automated ingestion backend using **Python (FastAPI)** and **Go** to fetch, clean, and ingest structured media catalogs into a relational database.
* Designed a normalized **PostgreSQL** schema with relational foreign keys, unique constraints, and composite indexes for sub-millisecond retrieval.
* Packaged the data store and ingestion workers using **Docker Compose** with dedicated Persistent Volumes, health check probes (`/healthz`), and zero-downtime schema migrations.

#### ⚡ [Distributed Tiered Storage & Caching Layer](https://github.com/xpmahdi/k8s-collaborative-todo)
* Architected a tiered data persistence solution pairing an in-memory **Redis** cache with a **PostgreSQL** relational store to minimize database query latency.
* Deployed storage engines with **Kubernetes StatefulSets** and PersistentVolumeClaims (PVC) to guarantee zero data loss across pod lifecycle events.
* Ran chaos drills simulating sudden worker teardowns to validate transaction integrity and data replication resilience.

#### 📊 Database & Pipeline Observability Stack
* Configured real-time metrics scraping for database disk I/O, active client pools, and host memory usage via **Prometheus** and **Node Exporter**.
* Authored alerting thresholds and visual **Grafana** dashboards to detect database bottlenecks and slow query patterns early.
